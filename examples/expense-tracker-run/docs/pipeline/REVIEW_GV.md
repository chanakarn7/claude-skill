## BLOCK
1. [B1] Filtered list on mobile: the category total overlaps the "ล้างตัวกรอง" button. The money figure "฿3,065.00" is drawn on top of the button text. The render check did not see it (`problems: []`). — evidence: `docs/mockups/screens/list-filtered-mobile-light.png` and `list-filtered-mobile-dark.png` (card under the filter select: "฿3,065.00" collides with "ล้างตัวกรอง"); desktop `list-filtered-desktop-light.png` is fine. Cause in `docs/mockups/index.html:211-213`: `.fsum` wraps, but `.lbl{flex:1;min-width:0}` lets the label shrink below its content (icon + "อาหาร" + badge + amount), so the amount overflows into the button. This is the PRD US-08 sum line and the only way to clear the filter on mobile. — fix: give `.lbl` `flex:1 1 auto` with `min-width:max-content` (or put the button on its own row below 480 px), then re-capture `list-filtered` and `list-filter-empty` at 390 px light and dark.
