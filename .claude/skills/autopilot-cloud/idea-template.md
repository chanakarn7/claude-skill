## 1. Requirement ★
- **ปัญหา / เป้าหมาย:** ทำไมต้องมี ใครเดือดร้อน
- **ผู้ใช้:** ใครบ้าง (บทบาท) ใช้บนอุปกรณ์อะไร กี่คน
- **ต้องทำได้ (ทีละข้อ ภาษาธรรมดา):**
  1. ...
  2. ...
- **ไม่ต้องมี (รอบนี้):** ...
- **กฎธุรกิจที่รู้แล้ว:** สูตรคำนวณ สิทธิ์ ข้อจำกัด ที่ห้ามให้ agent เดา
- **ข้อมูล:** มีข้อมูลเดิม/ไฟล์ Excel ให้นำเข้าไหม ข้อมูลตัวอย่างอยู่ที่ไหน
- **ไฟล์/ของเดิมที่ต้องใช้:** ใส่ **path เต็มหรือ URL ของทุกไฟล์** (โลโก้ ไฟล์ตัวอย่าง เอกสาร API) agent อ่านได้เฉพาะสิ่งที่อยู่ในโปรเจกต์หรือเข้าถึงได้จริง ถ้าไม่มี path ให้คัดลอกเข้า `docs/inputs/` หรืออธิบายเป็นตัวเลขในเอกสารนี้ (เคยพลาดมาแล้ว: อ้างไฟล์ Excel ที่ agent ไม่มี)
